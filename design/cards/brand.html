Accent usage

Do

  • Tint progress bars, prominent buttons, switches, and the drag-and-drop overlay with the flat accent #6E45E2.
  • Reserve the gradient for the app icon and brand lockups.
  • Use the 10% accent tint for transient highlights — duplicate-row flash, update banner, drop overlay fill.

Don’t

  • Don’t use the gradient on buttons, bars, or any interactive control — it reads as decoration, not state.
  • Don’t set body text or status lines in accent; text stays in the label hierarchy.
  • Don’t use accent for success, failure, or warning — those belong to green, red, and amber.
